## Two Prompts. One Song.

> Send these in order to your favorite agent:

### 1. Install

```text
Read https://talkoda.com/install.md and install Talkoda CLI and the skill for this agent.
```

### 2. Create

```text
Use the talkoda skill to turn this conversation into music and publish it publicly on Talkoda.
```
